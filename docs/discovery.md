# E01 discovery — external work outstanding

No buyer interview, pilot commitment, hardware certification or funding approval is represented as completed.

Record each operator's current BNG/CGNAT/RADIUS/version/hardware, topology and handoff, IPv4/IPv6/PPPoE/IPoE needs, VLAN/QinQ/MTU/identity rules, busy-hour traffic, subscriber count, flow churn, accounting/traceability retention, billing integration, recovery constraints, support hours, budget and migration/rollback criteria. Use anonymised examples and never source production credentials.

For 10–15 interviews, record named consent/contact owner and evidence date, operational pain, reason to switch, blockers, required first profile, acceptable exclusions and willingness to fund a pilot. Seek 2–3 design partners with named technical contacts and real lab access. Produce a common-core versus customer-specific matrix. None can be inferred from a working lab.

First profile decisions needing operator approval: access protocol and topology, supported CPE, L3 MTU, NIC/hypervisor/OS, routing integration, subscriber/flow/traffic targets, NAT attribution policy, RADIUS failure policy, maintenance/rollback method and pilot cohort. There is no authorization to attach this experiment to a live network.
