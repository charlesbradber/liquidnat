GET SPECIFIC

Put both proposals through the same test.

Access requirements

List PPPoE, IPoE, relay behaviour, CPE profiles and any L2TP requirements. Ask each supplier to identify exact supported configurations.

CGNAT behaviour

Compare protocols, allocation modes, mapping retention, lookup workflows and outcomes when logging or pools are under pressure.

Operational fit

Ask each supplier to demonstrate a failed login, wrong VLAN, pool exhaustion and package change using the proposed system.

Performance evidence

Use the same hardware basis, traffic mix and enabled features. Compare simultaneous flows and new-flow rate alongside bandwidth.

Resilience

Separate NAT flow continuity, subscriber continuity, packet interruption and route convergence. Request failure-test evidence.

Commercial fit

Request written software, hardware, support, renewal, migration and capacity terms. Compare cost over your own planning period.
