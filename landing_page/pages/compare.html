Ask better questions.

What is the combined workload?

Request packet rate, flow churn, subscriber count, shaping, mapping logs and failover reserve in the same test profile.

What happens in an outage?

Ask separately about the UI, control plane, RADIUS, database, node failure and site loss.

What will migration leave behind?

Ask for explicit mappings, unsupported settings, credential handling, rollback and accounting reconciliation.
