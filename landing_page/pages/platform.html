THE REST OF THE LIFECYCLE MATTERS

Install. Operate. Recover. Repeat.

Installation & compatibility

Define the Linux appliance, server, NIC, firmware and virtualisation profile. Include interface roles, management access, time synchronisation, certificates and a first-subscriber health check.

Security & access

Review administrator roles, MFA/SSO requirements, scoped API credentials, audit access and customer-controlled support access. Keep privileged diagnostics bounded and sensitive data out of routine logs.

Backups & updates

Include signed release artifacts, compatibility preflight, configuration backup, update order and a recovery path. Review image, database and state-schema compatibility together.

Resilience by data class

Configuration replication, NAT allocations, subscriber sessions and routing convergence have different recovery needs. Specify fencing, failover headroom and restoration expectations.

Licensing & support

Ask about local entitlements, offline operation, renewal, hardware replacement and service behaviour during vendor-service outages. Define support hours and escalation scope in the commercial proposal.

Documentation & diagnostics

Keep setup, troubleshooting and recovery guidance aligned with the installed version. Review offline recovery, diagnostic bundles, event retention and integration contracts as part of onboarding.
